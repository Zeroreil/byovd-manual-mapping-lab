# 06 · 隐藏面与检测

> 本文件从**防守方视角**列出常见的隐藏面、可观测的矛盾点和检测方法。它不提供摘链、摘名、模块隐藏或对象隐藏的实现步骤。

## 1. 核心原则

隐藏的本质是**让一个视角看不到**。防守方的机会是：**另一个视角仍然看得到**。

```text
服务注册表  ←→  驱动对象 / 设备对象
模块链表    ←→  池中的 PE / 可执行页 / 内核栈
设备符号链接 ←→  已打开的句柄 / 设备对象
磁盘文件    ←→  内核代码页 / 内存镜像
回调列表    ←→  回调地址所属模块
进程链表    ←→  PspCidTable / 线程 / 句柄
```

单点隐藏几乎一定会留下跨视角矛盾。检测设计应优先做交叉校验，而不是只查一个链表。

## 2. 隐藏面清单

### 2.1 服务与注册表

**隐藏方式（概念）**：删除 `HKLM\SYSTEM\CurrentControlSet\Services\<name>`、改 `Start`、删 `ImagePath`。

**检测**

- SCM 枚举 vs `Services\` 注册表；
- 驱动对象存在但服务不存在；
- 服务创建/删除事件（4697、7045）；
- 驱动文件存在但无服务；
- 服务名与驱动对象名不一致。

### 2.2 驱动对象

**隐藏方式（概念）**：从 `\Driver` 对象目录摘名，或创建无名驱动对象。

**检测**

- `\Driver` 枚举 vs `PsLoadedModuleList`；
- 驱动对象地址 vs 已知模块范围；
- 驱动对象的 `DriverStart`/`DriverSize` 是否落在合法映像；
- 对象目录中的孤立设备对象。

### 2.3 模块链表

**隐藏方式（概念）**：从 `PsLoadedModuleList` 摘链。

**检测**

- 池扫描：`MZ`/`PE\0\0`、节表、可执行保护；
- 内核栈采样：返回地址是否落在已知模块；
- 回调/线程/workitem 起始地址；
- 代码页哈希 vs 磁盘文件；
- `SystemModuleInformation` vs 内存扫描。

### 2.4 设备与符号链接

**隐藏方式（概念）**：删除 `\DosDevices\...` 符号链接，或对设备对象摘名。

**检测**

- 设备对象 vs 符号链接；
- 已有句柄仍能 IOCTL（句柄表）；
- `\Device` / `\GLOBAL??` 枚举；
- 对象管理器中的孤立设备；
- 设备 ACL 与调用方。

### 2.5 句柄与对象

**隐藏方式（概念）**：关闭句柄、摘对象、伪造引用。

**检测**

- 句柄表 vs 对象引用计数；
- 进程退出后对象仍存活；
- 设备对象被打开但无对应文件/服务；
- 句柄审计（Event 4656/4663）。

### 2.6 内核内存

**隐藏方式（概念）**：清 PE 头、改保护、把代码放进池/空洞、恢复代码字节。

**检测**

- 可执行池页；
- RWX 页；
- 内存 vs 磁盘节差异；
- 池标签异常；
- 代码完整性/HVCI；
- 内核代码页哈希基线。

### 2.7 回调

**隐藏方式（概念）**：注册 Ob/Ps/CM 回调后隐藏注册记录，或使用 inline hook。

**检测**

- 回调列表 vs 模块归属；
- 回调地址是否在已知模块范围；
- 回调注册/注销事件；
- 内核代码完整性；
- 句柄操作与回调行为关联。

## 3. 交叉校验矩阵

| 视角 A | 视角 B | 矛盾 = 可疑 |
|---|---|---|
| 服务列表 | 驱动对象 | 有驱动对象、无服务 |
| 模块链表 | 池扫描 | 有 PE/可执行页、无模块 |
| 符号链接 | 句柄表 | 无符号链接、已有句柄可 IOCTL |
| 磁盘文件 | 内核代码页 | 文件删除、代码页仍可执行 |
| 进程链表 | PspCidTable/线程 | 进程不可见、线程仍存在 |
| 回调列表 | 模块范围 | 回调地址不在任何模块 |
| 设备对象 | 驱动对象 | 设备存在、驱动对象无名 |

## 4. 检测工程建议

1. **先建基线**：正常机器的驱动/服务/设备/模块列表、池标签、代码页哈希。
2. **做差分**：同一台机器不同时间、不同快照、内存 vs 磁盘。
3. **多视角关联**：单点信号只报警，不直接定性。
4. **降低误报**：JIT、测试驱动、安全产品也会用可执行池/无名对象；需要签名/路径/行为上下文。
5. **保留证据**：驱动文件、服务注册表、设备对象、句柄、内存快照、事件时间线。

## 5. 缓解

- HVCI / 内核代码完整性；
- WDAC / 驱动白名单；
- Microsoft Vulnerable Driver Blocklist；
- 限制 `SeLoadDriverPrivilege`；
- 监控服务创建、驱动加载、设备打开、IOCTL；
- 定期内核内存基线/差分；
- 对高风险驱动做签名者/哈希/版本白名单。

## 6. 公开边界

本仓库不提供：

- DKOM 摘链；
- 对象目录摘名；
- 模块链表隐藏；
- 池 PE 头清零；
- 回调隐藏/inline hook；
- 任何可直接运行的隐藏 loader。

这些实现不进入公开仓库。检测矩阵和缓解措施是本仓库的交付重点。
