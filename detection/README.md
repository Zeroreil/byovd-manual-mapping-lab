# Detection Content

这些规则是**模板**，用于演示如何把 BYOVD / 手动映射 / 隐藏面的遥测转成检测逻辑。它们不是开箱即用的生产规则。

## 文件

| 文件 | 用途 | 注意事项 |
|---|---|---|
| `sigma/byovd-driver-service.yml` | 内核服务创建 | 7045 的 `ServiceType` 字段名/值随系统版本变化 |
| `sigma/driver-load-unsigned.yml` | 未签名/测试签名驱动加载 | `SignatureStatus` 字段依赖 Sysmon/EDR |
| `kql/driver-load.kql` | Defender XDR / Sentinel 模板 | 表/列名需按环境调整 |
| `yara/README.md` | 为什么“文件 YARA”不够 | 手动映射主要是内存问题 |

## 调参建议

1. 先跑 7–14 天基线，记录合法驱动/服务/设备。
2. 对 `System32\drivers` 的签名驱动做白名单，不要直接排除整个目录。
3. 把“服务创建 + 驱动加载 + 设备打开”做成关联规则。
4. 对手动映射，优先做**内存扫描 + 模块外代码**，不要只靠文件哈希。
5. 对测试签名/未签名驱动，区分开发机与生产机。

## 误报

- 软件更新/驱动安装会创建 7045；
- 安全产品/虚拟化产品会加载自己的驱动；
- JIT/调试器可能使用可执行池；
- 测试签名在开发机是正常的。

规则上线前必须用本地基线回归。
